# Career source guide

These are source-finding anchors for distinct events, not explanations of
private motives. Read the relevant source through BDP before answering.

## Leaving Microsoft for Telerik

- Source ID: `blog:2011/12706`
- Published: December 13, 2011
- [Goodbye Microsoft, Hello Telerik!](https://sellsbrothers.com/12706)
- Describes work at Microsoft and the next role leading a Telerik division
  covering developer tools and UI controls. States a goal of making developers'
  lives better. Enthusiasm about Telerik doesn't establish a private reason
  for leaving Microsoft, or prove there was no dissatisfaction.


## Joining Google

- Source ID: `blog:2014/13737`
- Published: November 1, 2014
- [Microsoft Fan Boy Goes To Google](https://sellsbrothers.com/13737)
- Describes joining Google to work on cloud developer tools. Despite the title,
  this is not the announcement of leaving Microsoft: the Telerik move was
  already announced in 2011. Don't conflate the Windows community with an
  employer or turn these separate moves into a direct Microsoft-to-Google move.

```sh
python3 <skill-dir>/scripts/bdp.py context 'blog:2014/13737'
```

Other career events need their own evidence. Search announcement language such
as goodbye, joining, hello and a company name, rather than only the user's
phrasing about leaving or quitting. If a search misses the event, don't replace
it with a different event that happens to mention the same company.
