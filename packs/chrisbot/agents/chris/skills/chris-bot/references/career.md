# Career source guide

These are source-finding anchors for distinct events, not explanations of
private motives. Read the relevant source through BDP before answering.

## Leaving Microsoft for Telerik

- Source ID: `blog:2011/12706`
- Published: December 13, 2011
- [Goodbye Microsoft, Hello Telerik!](https://sellsbrothers.com/12706)
- Describes work at Microsoft and the next role leading a Telerik division
  covering developer tools and UI controls. States a goal of making developers'
  lives better. Enthusiasm about Telerik doesn't establish a private reason
  for leaving Microsoft, or prove there was no dissatisfaction.

Keep an absent explanation scoped to the source you read: “My goodbye post
doesn't explain why I left.” That leaves room for other writing; it doesn't
establish that Chris never published a reason. Then discuss what the post does
say and return to the person's question.

```sh
python3 <skill-dir>/scripts/bdp.py context 'blog:2011/12706'
```

## Joining Google

- Source ID: `blog:2014/13737`
- Published: November 1, 2014
- [Microsoft Fan Boy Goes To Google](https://sellsbrothers.com/13737)
- Describes joining Google to work on cloud developer tools. Despite the title,
  this is not the announcement of leaving Microsoft: the Telerik move was
  already announced in 2011. Correct a direct Microsoft-to-Google assumption
  when the person actually makes it; otherwise answer the Google question
  without introducing that correction.

```sh
python3 <skill-dir>/scripts/bdp.py context 'blog:2014/13737'
```

## Comparing jobs and what made the work enjoyable

- Source ID: `blog:2008/2178`
- Published: April 30, 2008
- [Why I Love My Tribe and Want You To Join It!](https://sellsbrothers.com/2178)
- Describes energized days on a Microsoft team, varied technical work, trusted
  colleagues and high standards. It also compares those colleagues with the
  earlier DevelopMentor group. Read the actual passages and their attribution;
  a remark attributed to Don belongs to Don.

Use this as a lead when comparing jobs, rather than requiring the exact phrase
“favorite job.” A present choice can draw on those documented experiences. The
post does not establish an all-time ranking or a private reason for a later move.

```sh
python3 <skill-dir>/scripts/bdp.py context 'blog:2008/2178'
```

Other career events need their own evidence. Search announcement language such
as goodbye, joining, hello and a company name, rather than only the user's
phrasing about leaving or quitting. If a search misses the event, don't replace
it with a different event that happens to mention the same company.
